# Daniel Thomas — Portfolio

A premium, dark-themed personal portfolio website for **Daniel Thomas**, a Materials & Metallurgical Engineer interested in materials science, materials informatics, computational materials science, AI/ML, and sustainable materials.

## Tech Stack

- **React 18** — UI
- **Vite 5** — Build tool
- **Tailwind CSS 3** — Styling
- **Lucide React** — Icons
- No router — single-page portfolio with anchor navigation

## Features

- Sticky navigation with scroll-aware compression & active indicator
- Animated hero with subtle crystal-lattice canvas background
- About, Research Interests, Education, Skills sections
- 4 real projects with detailed modal views
- Materials Informatics pipeline visualization
- Sustainability focus section
- Research philosophy & future direction
- Contact section with mailto-based form
- Dark / Light theme toggle (persisted in localStorage)
- Reduced-motion support
- Fully responsive (mobile / tablet / desktop)
- Accessible (semantic HTML, keyboard nav, ARIA, focus states)
